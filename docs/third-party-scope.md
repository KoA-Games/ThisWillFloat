# Third-Party Scope

This repository is a prototype workspace and includes third-party assets used for visual context and rapid iteration.

Examples include packages for water, sky, vegetation, rocks, props, terrain materials, scans, and post-processing. Their presence in the repository does not imply authorship by KoA Games. Each package remains subject to its original license and attribution requirements.

## Custom engineering highlighted by this portfolio

The recruiter-facing case study is limited to the following custom work:

- `Assets/_Project/Scripts/Prototype/` — modular raft, buoyancy, cargo, connector, camera, and demo-control code
- `This will float DEMO/Assets/_Project/Scripts/` — project-specific runtime systems
- `This will float DEMO/Assets/_Project/Editor/` — project-specific Unity editor and scene-generation tools
- `This will float DEMO/Assets/_Project/R70VolcanoMigration/` — R70 migration code, metadata, reports, and integration assets on the active migration branch
- Selected scripts under `This will float DEMO/Blender/Volcano/` — Blender automation, deterministic placement, export, and validation
- Project-authored reports and fixed-camera validation captures produced by those tools

## Representative external packages

The workspace contains packages such as AQUAS-Lite, FastSky, NVJOB Water Shaders, Palm Tree Pack, PolyOne Rocks Stylized, AwesomeFreeScans assets, Yughues sand materials, and other environment or prop packs.

These are dependencies or presentation assets. Their shaders, models, textures, example scenes, and package scripts are excluded from claims about custom engineering work.

For a code review, begin with the linked files in the root README and Engineering Case Study rather than evaluating the full asset tree.
